# АйтиКонфа — лендинг IT-конференции

Статический одностраничный сайт для конференции **АйтиКонфа** (Алматы, 18–20 августа 2026): блоки «Главная», «Спикеры», «Почему мы», «Купить билет» и подвал с контактами.

## Стек

- HTML5, CSS (`styles/style.css`)
- [GSAP](https://gsap.com/) (локальные минифицированные скрипты в `scripts/`):
  - **ScrollToPlugin** — плавная прокрутка по якорным ссылкам в шапке
  - **ScrollTrigger** — появление секций при скролле

## Структура проекта

confere-project/

├── styles/

│

## Как открыть локально

Сборки и зависимостей (npm и т.д.) нет. Достаточно открыть `index.html` в браузере или поднять простой HTTP-сервер в корне проекта, если нужен корректный путь к ресурсам в особых окружениях.

Пример с Python:

```bash
cd confere-project
python3 -m http.server 8080

Затем в браузере: http://localhost:8080.
